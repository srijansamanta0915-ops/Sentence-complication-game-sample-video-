🧩 Sentence Completion Puzzle

A simple, interactive grammar game in C, designed to help users practice sentence structure, prepositions, conjunctions, and context comprehension.

🎯 About Us

The game contains 5 sentence completion questions. Users enter their answers, get their score scored during the game and get feedback immediately.

✨ Highlights
- 📝 5 contextual questions

- ⚡ Immediate feedback

- 📊 Automatic score keeping

- 🏆  Final performance assessment- 💻 Simple implementation in C

- 🧠 Focuses on fundamental language and grammar skills

🎮 How It Works
The program follows a simple quiz-based flow:
Start Game
    ↓
Display Instructions
    ↓
Present Sentence Completion Question
    ↓
User Enters Answer
    ↓
Check Answer
    ↓
Display Immediate Feedback
    ↓
Update Score
    ↓
Repeat for 5 Questions
    ↓
Display Final Score
    ↓
Show Performance Evaluation
    ↓
Display Awareness Message
The game contains five context-based questions.
For every question:
A sentence with a missing word is displayed.
The user provides an answer.
The program checks the response.
Immediate feedback is provided.
The score is updated.
After all five questions, the final score and evaluation are displayed.
